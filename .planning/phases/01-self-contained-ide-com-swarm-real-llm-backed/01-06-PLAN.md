# Plan 01-06 — Phase 1 Verification

## Goal

Install and configure the test infrastructure (Vitest + Playwright) that was deferred from earlier plans, and write a baseline of tests that prove Phase 1's success criteria are met. This is the gate before moving to Phase 2.

## Context

- **What exists today:** zero tests in the repo (verified by the codebase map). The 5 plans above have written a few inline unit tests (`*.test.ts`) but there's no test runner config, no CI, no E2E.
- **What this plan delivers:**
  1. `vitest.config.ts` with `jsdom` env and the `@/*` alias.
  2. `playwright.config.ts` with Chromium + WebKit + Firefox.
  3. A baseline test suite covering the new Phase 1 modules.
  4. An E2E spec that walks the success criteria.
  5. A `VERIFICATION.md` summarizing pass/fail.
- **Why now:** without verification, we can't claim Phase 1 done. Also sets the foundation for Phase 4 (Tests + CI).

### Task 1.6.4 — Write the Phase 1 E2E spec

- `e2e/phase-01.spec.ts`:
  ```typescript
  test('Phase 1: self-contained IDE with Swarm', async ({ page }) => {
    // 1. Open AnjosDevOS, see Workspaces view
    await page.goto('/');
    await expect(page.getByText('Workspaces')).toBeVisible();

    // 2. Create a new workspace "test-ws"
    await page.getByRole('button', { name: /novo workspace/i }).click();
    await page.getByPlaceholder('Nome do workspace').fill('test-ws');
    await page.getByRole('button', { name: /criar/i }).click();

    // 3. Open the workspace, lands in Code Editor (4 panels)
    await page.getByText('test-ws').click();
    await expect(page.getByRole('region', { name: /sidebar/i })).toBeVisible();
    await expect(page.getByRole('region', { name: /editor/i })).toBeVisible();
    await expect(page.getByRole('region', { name: /swarm/i })).toBeVisible();
    await expect(page.getByRole('region', { name: /terminal/i })).toBeVisible();

    // 4. Create a new file
    await page.getByRole('button', { name: /new file/i }).click();
    await page.getByPlaceholder('path').fill('src/index.ts');
    await page.getByRole('button', { name: /criar/i }).click();

    // 5. Type code with a known bug
    const editor = page.locator('.monaco-editor').first();
    await editor.click();
    await page.keyboard.type('export function add(a, b) { eval("return a + b"); }\n');
    await page.keyboard.press('Control+s');

    // 6. Run an audit (mocked LLM via API route override)
    await page.route('**/api/chat', (route) => {
      route.fulfill({ json: { choices: [{ message: { content: '{"score":42,"issues":[{"severity":"critical","line":1,"title":"eval","description":"use of eval is dangerous","suggestion":"use return","fixedCode":"export function add(a, b) { return a + b; }"}],"summary":"bad"}' } }] } });
    });
    await page.getByRole('button', { name: /auditar/i }).click();
    await expect(page.getByText('eval')).toBeVisible();
    await expect(page.getByText('critical')).toBeVisible();

    // 7. Apply the patch
    await page.getByRole('button', { name: /aplicar correção/i }).click();
    await page.getByRole('button', { name: /aceitar/i }).click();
    await expect(editor).toContainText('return a + b');
    await expect(editor).not.toContainText('eval');

    // 8. Reload, verify the workspace is restored
    await page.reload();
    await expect(page.getByText('test-ws')).toBeVisible();
    // The file should be restored from the VFS snapshot.
    await page.getByText('src/index.ts').click();
    await expect(editor).toContainText('return a + b');
  });
  ```
- Commit: `test(e2e): add Phase 1 happy-path spec`.

## Risks

- **WebContainer boot in CI:** Playwright runs against a real `pnpm dev` server. WebContainer works in headless Chromium with the right flags. If it doesn't, the E2E should skip the WebContainer-dependent steps and use a mock runtime.
- **Dexie in jsdom:** requires `fake-indexeddb`. Easy to forget; add to `test-setup.ts` from the start.
- **First E2E run may be flaky** (WebContainer boot is timing-sensitive). Use Playwright's auto-waiting and `expect(...).toBeVisible({ timeout: 30_000 })` generously.
