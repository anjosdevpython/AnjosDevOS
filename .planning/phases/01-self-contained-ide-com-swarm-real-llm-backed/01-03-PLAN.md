# Plan 01-03 — Code Editor Consolidado (4-panel IDE)

## Goal

Refactor `CodeEditorApp.tsx` (currently a single-pane editor with terminal) into a **proper 4-panel IDE**:
- **Left sidebar**: file tree + file search + symbol search.
- **Center**: Monaco editor with tabs and multi-cursor.
- **Right**: `✨ IA Swarm` panel (placeholder in this plan; the real one ships in Plan 1.4).
- **Bottom**: real xterm.js terminal (from Plan 1.2).

Resizable splitters, keyboard shortcuts, restored session on reload.

## Context

- **What exists today:** `src/components/os/apps/CodeEditorApp.tsx` is 983 lines. Single pane: tabs on top, Monaco in the middle, a mock status bar at the bottom. No file tree, no search, no IA panel.
- **What this plan delivers:** the 4-panel layout, file tree backed by the active workspace's VFS, file/symbol search, keyboard shortcuts, and session restore (open tabs + cursor positions + active file).
- **Why now:** Plans 1.4 and 1.5 mount their UI in the right panel and bottom panel respectively. The layout has to exist first.

## Tasks

### Task 1.3.2 — Create `src/components/os/panels/FileTreePanel.tsx`

- `'use client'`. Props: `{ workspaceId: string }`.
- Reads the file tree from the WebContainer's `fs.readdir('/', { withFileTypes: true })` recursively (or from a cached snapshot in `useRuntimeStore`).
- Renders a recursive tree with folder/file icons (lucide `Folder`, `FolderOpen`, `File`, `FileCode`, etc.).
- Click on file → emits `onFileOpen(path)` (caller opens in editor).
- Right-click context menu: New File, New Folder, Rename, Delete (Plan 1.5 wires the actual fs operations).
- Header with: workspace name, refresh button, search input (filters tree by name).

### Task 1.3.3 — Create `src/components/os/panels/SearchPanel.tsx`

- `'use client'`. Two modes: "Files" (`Ctrl+P`) and "Symbols" (`Ctrl+Shift+O`).
- Toggled by a tab strip at the top of the sidebar.
- "Files" mode: type-ahead input, fuzzy match against file paths, Enter to open.
- "Symbols" mode: greps file content (or reads TS symbols via Monaco's `monaco.languages.getDocumentSymbols` for the open file) for matches.
- Reuse the file tree's on-open callback.

### Task 1.3.4 — Create `src/components/os/panels/SwarmPanel.tsx` (placeholder)

- `'use client'`. Props: `{ workspaceId: string }`.
- For this plan: a placeholder that shows the 7 agent names from `getSwarmEngine().getAllAgents()` as cards (name, role, status badge).
- Plan 1.4 will replace the placeholder with the real `Auditar` / `Auto-Patch` / `Gerar Testes` buttons and live status.
- A bottom "Ask Swarm" input that for now shows "Disponível em breve" (Plan 1.4 wires it).

### Task 1.3.5 — Refactor `CodeEditorApp.tsx` into the 4-panel layout

- Use `react-resizable-panels`:
  ```tsx
  <PanelGroup direction="horizontal">
    <Panel defaultSize={20} minSize={15}><FileTreePanel workspaceId={...} /></Panel>
    <PanelResizeHandle />
    <Panel defaultSize={55}>
      <PanelGroup direction="vertical">
        <Panel defaultSize={70}>
          <Tabs + Monaco editor + status bar />
        </Panel>
        <PanelResizeHandle />
        <Panel defaultSize={30}><Terminal workspaceId={...} /></Panel>
      </PanelGroup>
    </Panel>
    <PanelResizeHandle />
    <Panel defaultSize={25} minSize={15}><SwarmPanel workspaceId={...} /></Panel>
  </PanelGroup>
  ```
- Tabs: array of `{ path, content, dirty }`. Click to switch, X to close, dirty dot indicator. (Existing tab code from the old single-pane can be extracted.)
- Monaco editor: the existing setup; just relocated. The "Save" button now writes to WebContainer VFS (`webcontainer.fs.writeFile(path, content)`).
- Status bar: file path, language, cursor position, WebContainer ready/idle.

### Task 1.3.6 — Keyboard shortcuts

- Use a `useEffect` with `addEventListener('keydown', ...)` on the panel grid wrapper.
- Implement:
  - `Ctrl/Cmd+P` → focus the file search input.
  - `Ctrl/Cmd+Shift+O` → focus the symbol search input.
  - `Ctrl/Cmd+`` (backtick) → toggle the bottom terminal panel (resize to 0 or 30%).
  - `Ctrl/Cmd+J` → toggle the right Swarm panel.
  - `Ctrl/Cmd+S` → save the active file to WebContainer VFS.
- Centralize shortcut definitions in `src/lib/runtime/shortcuts.ts` for reuse.

### Task 1.3.7 — Session restore (open tabs + cursor + active file)

- On every change (open file, close tab, cursor move, active file change), debounced save to the `EditorSession` in Dexie:
  ```typescript
  saveSession({
    id: workspaceId,
    workspaceId,
    openTabs: [{ path, cursor: { line, column } }],
    activeTab: path,
    terminalHistory: [...], // managed by Terminal panel
    updatedAt: new Date(),
  });
  ```
- On app boot (or workspace activation), `useEffect` calls `restoreSession(workspaceId)` and seeds the tabs + active file in the editor.
- The cursor is set via `monacoEditor.setPosition({ lineNumber, column })` after the file is loaded.

### Task 1.3.8 — Empty state for no active workspace

- If `useWorkspacesStore.activeWorkspace === null`, render a centered prompt: "Selecione ou crie um workspace para começar." with a button that opens the Workspaces app.
- Prevents the editor from booting in a broken state.

## Out of scope (deferred)

- **Symbol indexing across files** (full workspace): only the currently open file is indexed for symbols. Full workspace indexing would need a separate background worker (Phase 2+).
- **Tabs reordering by drag:** nice-to-have, can ship in v1.1.
- **Editor settings UI** (font size, tab size, theme picker): a stub is fine for v1; Phase 3 settings page covers it.

## Risks

- **`react-resizable-panels` SSR:** wrap in `'use client'` and import dynamically if needed.
- **Monaco in resizable panel:** the `DiffEditor` and Monaco need to call `editor.layout()` on resize. Add an `onLayout` callback in the panel wrapper that finds the Monaco instance and calls `layout()`.
- **VFS sync between WebContainer and file tree:** file tree reads from `fs.readdir` on mount and after `fs.writeFile`. Plan 1.5 will centralize this via a `useVfsSnapshot` hook.
